# NeuroSpecification

- Status: locked
- Researcher approval: Approved in conversation on 2026-09-03.

## Researcher request
- Brain-modeling question or behavior: Determine whether a sparse current-based excitatory/inhibitory LIF network exhibits the requested synchronous regular, fast synchronous irregular, asynchronous irregular, and slow synchronous irregular regimes under four specified `(g, eta)` conditions.
- Requested model, experiment, or comparison: Simulate `NE = 10,000` excitatory and `NI = 2,500` inhibitory neurons. Give every target exactly `CE = 1,000` excitatory and `CI = 250` inhibitory recurrent afferents, sampled without replacement within each source population. Use `Cext = 1,000` statistically independent external Poisson afferents per neuron. Use `tau_m = 20 ms`, absolute refractory period `t_ref = 2 ms`, threshold `20 mV`, reset `10 mV`, excitatory delta jump `JE = 0.1 mV`, inhibitory delta jump `JI = -g JE`, and recurrent delay `1.5 ms`. Use external per-afferent rate `nu_ext = eta * theta / (JE * CE * tau_m)`. Run `(g, eta) = (3, 2), (6, 4), (5, 2), (4.5, 0.9)` over one fixed seed set.
- Execution mode: forward-simulation
- Required outputs: Save a four-condition PNG with, for each condition, instantaneous whole-network rate in `0.1 ms` bins and its temporal mean above a raster from one fixed random 50-neuron sample. Save PNG diagnostics for excitatory/inhibitory rates, ISI coefficient of variation, and the whole-network-rate spectrum. Save machine-readable metrics and report each condition's dominant non-DC frequency. List every PNG path.
- Constraints: Build from first principles using only this specification. Do not search for or inspect papers, existing implementations, or prior workspace cases. Use BrainX-native point-neuron, event-connectivity, unit, state, and execution APIs where the applicable skills require them. Do not force the requested regime names when the observables do not support them.

## Inspected data contract
- Data sources and inspected contents: No external data were supplied. The researcher provided all model parameters and requested observables in text.
- Shapes, axes, sampling/time base, and physical units: `12,500` point neurons split into `10,000 E + 2,500 I`; membrane voltage in mV; time in ms; rates in Hz; recurrent delay `1.5 ms`; output-rate bins `0.1 ms`. The numerical integration step is provisionally `dt = 0.1 ms` so the output bin and delay are exact integer step counts.
- Required preprocessing and the subset used to fit each transform: None. Discard interval is unresolved. Spectral detrending/windowing and valid frequency band will be frozen before outcomes are viewed.
- Mapping from data to model inputs, targets, and observables: Aggregate `Cext` independent Poisson afferents into an independent per-neuron Poisson event count with mean `Cext * nu_ext * dt`; each external event jumps voltage by `JE`. Recurrent spikes are delivered after exactly 15 steps. Population spike counts map to `rate = spikes / (population_size * bin_width)`. ISI CV is computed per neuron with enough post-transient intervals, then summarized without pooling intervals across neurons. Spectrum is computed from the demeaned post-transient global-rate series.
- Known data limitations or unresolved mismatches: Run each condition for `5 s` and discard the first `1 s`. Use fixed seeds `11`, `29`, and `47`. For each seed, share the connectivity realization, initial voltages, and fixed random 50-neuron sample across all four conditions. Initialize voltages uniformly on `[10, 20) mV`. Use `dt = 0.1 ms`. Requested qualitative regimes are operationalized by the frozen criteria below rather than by any external source.

## Acceptance boundary
- Evidence required for success, failure, or an inconclusive result: For every seed and condition, preserve global/E/I rate series, sampled raster events, per-neuron ISI CV values, power spectrum, mean rates, CV summary, and dominant non-DC frequency. Label neuronal firing `regular` when the across-seed median neuronal ISI CV is `<= 0.5`, `irregular` when it is `>= 0.8`, and `indeterminate` otherwise. Label the population `synchronous` only when the same non-DC peak is significant in the global-rate spectrum across seeds under a frozen narrowband prominence test; otherwise label it `asynchronous` or `indeterminate` as defined before production results are viewed. Divide slow from fast synchronous activity at `30 Hz`. Verify the requested label only when all predicates pass across the declared seed aggregation; otherwise report the measured label or an inconclusive result.
- Required baselines and controls: Verify exact recurrent indegrees; zero self-connections when source and target are the same neuron; inhibitory jump sign and magnitude; 15-step delay; refractory duration; external Poisson count mean/variance; deterministic replay for a repeated seed; and a small-network reference transition test before production execution.
- Invalid-result conditions: Wrong population or connectivity shapes; non-finite state or metrics; missed/double-counted delayed events; rates normalized by the wrong population size or bin width; spectrum including DC as the dominant oscillation; ISI CV pooled across neurons; seed-dependent figure neuron samples; or any qualitative label assigned after tuning its thresholds against these four outcomes.
- Allowed claims and explicit non-claims: Claim only that this implementation, parameter set, initialization, duration, numerical step, and frozen seeds produce the measured finite-simulation regimes. Treat the regime mapping as phenomenological and unsourced. Do not claim reproduction of prior literature, biological realism beyond the stated LIF model, uniqueness, or asymptotic stationarity.
