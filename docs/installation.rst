Installation
============

Install BrainX Skill into a supported coding agent. The installer selects the agent and whether to install globally or in the current project.

Requirements
------------

- Node.js 18 or newer
- macOS, Linux, or Windows

Install
-------

.. code-block:: bash

   npx brainx-skill install

Update
------

Update every BrainX-managed skill recorded by the installer.

.. code-block:: bash

   npx brainx-skill update
