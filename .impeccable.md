## Design Context

### Users

Researchers and scientific-software developers use this repository to evaluate
and install BrainX Agent Skills for their coding agents. They need to identify
compatibility, currency, and trust signals quickly.

### Brand Personality

Credible, scientific, and polished. The presentation should feel maintained and
authoritative without becoming promotional or visually loud.

### Aesthetic Direction

Use NVIDIA's Agent Skills README as the badge-quality reference: compact rounded
Shields badges, dark neutral labels, restrained semantic color, consistent
typography, and minimal icon use. Avoid sharp `flat-square` badges, neon color
mixtures, decorative logos, and inconsistent label casing.

### Design Principles

1. Make evidence and compatibility easy to scan.
2. Use color semantically: blue for information, green for success, and warning
   colors for genuine risk.
3. Keep badge geometry, typography, casing, and spacing consistent.
4. Prefer restrained clarity over decorative density.
5. Preserve truthful status signaling even when a warning color is less pretty.
